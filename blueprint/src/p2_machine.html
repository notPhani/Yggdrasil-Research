§1 · the whole machine

Four units, four contracts, one clock

For a ten-year-old

Picture a detective who reads every newspaper in the world, every fifteen minutes, long before anything goes wrong. The detective keeps a giant map of stories: which ones people are talking about, and which stories make other stories louder.

One day a toy company's price suddenly crashes. The detective may use only the newspapers they had already read before the crash, because peeking at tomorrow's paper is cheating. Using the map, the detective finds the shortest chains of stories that could explain the crash. Then the detective goes looking for clues that would prove each chain wrong. At the end they say which chains survived and which didn't, or they honestly say "I don't know".

Yggdrasil is one deterministic program that steps through time in 15-minute windows. Each step reads one GDELT batch, updates the world model, and checks the market. When the market does something abnormal, it opens a case and searches the frozen world model as it stood at the moment the move began. The world model is built without regard to any stock. Explanations are reads from that state, not fresh investigations. design

Each unit has one job and one deliberate blind spot

Engine 1 · ObservationOwns the archive, copy groups, clocks and the fetch service. Never interprets meaning: no relevance filter, no narratives, no stock filter, so "bridge" stories survive.
Engine 2 · Narratives and attentionOwns events, narratives, phenomena, memberships, attention state and edge shares. Never sees prices and never searches the web. The narrative graph can't be shaped by the move it will later explain.
Stock observerOwns prices, abnormal-return statistics, clusters and τ*. Never reads news.
Engine 3 · ExplanationOwns the explanation graphs, search, queries, claims, programs, verdicts and dossiers. Never writes to Engine 2's state.
2a → 2b, one wayGrouping decides by content alone. Attention is computed afterwards. Grouping never reads attention (decision 3.9′: the Dirichlet–Hawkes coupling was rejected as scope encroachment).
The one-way valveTargeted pages are evidence, never attention. Without the valve, the search would choose what to fetch, the fetched pages would count as attention, and the model would get stronger on the very hypothesis it was asked to test. Since A1 the valve is structural, not a tag: targeted pages live in their own table that Engine 2 cannot read, and test T0 requires identical Engine 2 snapshots with SerpApi on and off.

One clock decides what counts as evidence

Every record carries four clocks that are never collapsed into one. event_time is when the thing happened. published_time is the outlet's timestamp, present for about 59% of GKG documents via PAGE_PRECISEPUBTIMESTAMP measured. observed_time is the batch time. ingested_time is observed_time + 15 min in a replay, which removes the wall clock. Admissibility uses a fifth, derived clock:

\[ \text{first_seen}(o) = \min_{o' \equiv o} \text{ingested_time}(o'), \qquad \text{admissible}(o, \tau^*) \iff \text{first_seen}(o) \lt \tau^* \]

Here \(o' \equiv o\) runs over every record with the same exact key (native id, canonical URL or content hash). A SerpApi page fetched in October 2026 has first_seen = October 2026, which would make it useless in a replay. Decision 0.6 fixes this: if its canonical URL matches a GDELT record, it inherits that record's first_seen. Otherwise it goes only into \(P_{\text{all}}\), the program that judges truth, and never into \(P_{\text{pre}}\), the program that judges what moved the price.

Proof · Theorem 3.1, end-to-end replay determinism (D1–D6; D7 adds causality)

Let \(x_0, x_1, \dots\) be the archived inputs (raw blobs plus archived model and API outputs) sorted by the D4 key, and let every stage be a state map \(s_{n+1} = \Phi(s_n, x_n, \text{cfg})\). Then \(s_0 = \text{init}(\text{cfg})\) depends only on the config. If \(s_n\) is a function of \((x_{\lt n}, \text{cfg})\), so is \(s_{n+1}\), provided \(\Phi\) reads nothing but its arguments. D1 removes the clock, D2 the RNG state, D3 the reduction order, D4 container iteration order, and D5 the outside world. By induction every state is a function of the inputs and the config, and every output is a projection of a state. QED

Rounding scores before threshold tests does not provide this guarantee, because a value can straddle a grid line. The guarantee comes from D3. Acceptance test: replay the same window range twice, and every snapshot hash and verdict must match bit for bit. Test T1 in §4 extends this to stopping and resuming from a snapshot.
